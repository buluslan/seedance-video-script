# 引用语法与素材配置 · reference-syntax

> **何时读**:分配素材时。@引用是 Seedance 提示词最关键的部分。

## @ 引用系统

通过 `@` 指定每个素材用途:
```
@图片1 @图片2 ... @图片N
@视频1 @视频2 ... @视频N
@音频1 @音频2 ... @音频N
```

### @ 用途表(务必明确每个引用的作用)

| 用途 | 写法 |
|---|---|
| 首帧 | `@图片1 作为首帧` |
| 尾帧 | `@图片2 作为尾帧` |
| 人物形象 | `参考 @图片1 的人物形象` |
| 场景/背景 | `场景参考 @图片3` |
| 运镜 | `参考 @视频1 的运镜效果` |
| 动作 | `参考 @视频1 的动作编排` |
| 特效 | `完全参考 @视频1 的特效和转场` |
| 节奏/节拍 | `视频节奏参考 @视频1` |
| 音色/语气 | `旁白音色参考 @视频1` |
| 背景音乐 | `背景BGM参考 @音频1` |
| 音效 | `音效参考 @视频3 的音效` |
| 服装 | `穿着 @图片2 的服装` |
| 产品外观 | `产品细节参考 @图片3` |
| 字体/文字 | `字体参考 @图片2 的字体` |

多引用组合:
```
@图片1 的人物作为主体,参考 @视频1 的运镜和动作编排,背景BGM参考 @音频1,场景参考 @图片2
```

## 主体定义(精准引用素材中的特定对象)

- 基本句式:`将@图片/视频N中的[2-3个稳定静态特征(服饰/发型/外观/类别)]定义为主体N`
  - 示例:`将@图片1中穿红色连衣裙、戴草帽的女人定义为主体1`
- 多素材同主体:统一绑定
- 多主体:分别定义 + 标签区分(将视频1中的高个子男人定义为警察,矮个子定义为小偷),后续持续用同一标签
- 指代:未定义用 `主体N@图片N`;已定义用标签
- ⚠️ 不用 Asset ID 替代 `@图片/视频N`(模型无法关联)

## 4 功能角色(素材配置策略)

| 角色 | 作用 |
|---|---|
| 角色锚定 | 锁定角色外观 |
| 场景定调 | 锁定环境与风格 |
| 运镜参考 | 锁定镜头语言与动作节奏 |
| 节奏氛围 | 用音频控制情绪、音色 |

**推荐配置(共 4-5 个)**:角色图 1-2 张(面部特写/全身)+ 场景图 1 张 + 运镜视频 1 段 + 音频 1 段

## 2.5 参考扩容:50 个上限 + 白模

- **2.5 参考**:最多 50 个(30 图 + 10 视频 + 10 音频),2.0 仅 4-5 个
- **⚠️ 精选不强堆**:推荐仍 4-5 个核心;用满 50 个反而让模型困惑(过多参考致风格冲突/主体识别模糊)
- **参考选择策略**:
  - 图像参考-主要主体 ≤8 个
  - 视频/音频参考主体 ≤5 个(片段 5-10 秒)
  - 多主体(>5 个)优先单视图图像
  - 优先级:核心角色 → 关键产品/道具 → 场景 → 整体风格

## 2.5 新增:白模参考 @白模N

3D 白模(无纹理)搭空间结构 / 主体姿态 / 运动轨迹 / 镜头机位,模型据此生成。白模还可携带光照信息生成物理光影。
- 用法:`参考 @白模1 的运镜、构图、景别` / `参考 @白模1 的主体轨迹`
- 与图片分工:白模控空间/运镜/轨迹,图片控外观/材质/色彩
  - 示例:`参考 @白模1 的运镜、构图,@图片1 的材质、光照、色彩`

## 人物参考注意(避 ID 漂移)

- 用大头照(人脸特写)+ 全身照,**不用多视图/三视图**(模型易识别为多主体)
- 重要素材放 prompt 越靠前位置
- 详见 pitfalls.md
