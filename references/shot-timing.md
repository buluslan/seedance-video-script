# 分镜时序 · shot-timing

> **何时读**:组织时间线时。2.5 核心新语法——时间戳分段。

## 2.0 → 2.5 的分镜演进

- **2.0**:「镜头1/镜头2/镜头3」按事件顺序,每镜=运镜+动作+空间+音频。模型对精确时间(如 0-3 秒)支持不稳定
- **2.5**:**时间戳分段成标配**——`0-5秒:...;6-10秒:...`,模型支持精准时间戳控制

## 时间戳分段写法(2.5)

按时间段组织,每段四件套:**主体 + 动作细节 + 运镜(一镜一种)+ 音频信息**

```
16:9 宽幅电影级质感,一镜到底,丝滑运镜,无剪辑。
0-5 秒:@图片2 霸王近景开场,镜头缓慢环绕,[动作]...
6-10 秒:镜头稳定环绕 @图片1 虞姬中景,[动作]...
11-20 秒:@图片3 武生出场完成空翻,[动作]...
```

### 每段组织逻辑
1. 运镜或镜头切换方式(全景缓慢推近/固定机位/镜头切至…)
2. 主体动作与表情(核心角色的关键动作、神态)
3. 位置或空间变化(场景、空间关系)
4. 音频信息(音效/人声/BGM,见 audio-design.md)

## 场景弧线(2.5 长场景推荐,20 秒+)

针对 30 秒长场景,用「开头 → 中段推进 → 结尾定格」节奏:
> 示例:「开场产品置于白色台面,镜头缓缓推近,光线由冷转暖,最后一帧定格在标签特写」

30 秒内可组织多个逻辑关联镜头:铺垫→推进→转折→收尾(非简单延续画面)。

## 注意

- 粒度按秒(2.5 支持精准时间戳),但模型对精确到帧的时间仍不稳,分段别太碎
- 一镜一种运镜(别同时推拉摇移,见 camera-language.md)
- 别在 4-5 秒塞太多场景(物理可行性 + 模型遵循度)
- 文案别过度冗余(直接把完整剧本塞进去会造成理解混乱,精简聚焦)

## 连续长镜头 vs 分段拼接

- **延长(连续长镜头)**:单一场景文戏(长对话/情绪递进/单路径移动),一镜到底沉浸感
- **分段拼接**:剧情转折/快速武戏(追逐/打斗/蒙太奇),独立生成片段再剪辑
- 实操常结合:延长生成连贯对话 + 拼接空镜转场
