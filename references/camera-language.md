# 运镜与景别 · camera-language

> **何时读**:写运镜/景别时。模型对运镜词理解力强,直接用标准术语。

## 核心原则

- **一镜只指定 1 种运镜**——不要同时要求推拉摇移,会增加画面不稳定
- 模型对运镜词理解力强,标准术语直接用

## 基础运镜

| 术语 | 说明 |
|---|---|
| 推镜头 / 慢推 | 镜头向主体靠近 |
| 拉镜头 / 后拉 | 镜头远离主体 |
| 左摇 / 右摇 | 镜头水平旋转 |
| 上摇 / 下摇 | 镜头垂直旋转 |
| 跟随镜头 / 跟拍 | 镜头跟随主体移动 |
| 环绕镜头 | 镜头围绕主体旋转 |
| 一镜到底 | 全程无剪辑连续镜头 |
| 固定镜头 | 机位不动 |

## 高级运镜

| 术语 | 说明 |
|---|---|
| 希区柯克变焦 | 推拉+变焦的眩晕效果 |
| 鱼眼镜头 | 超广角畸变镜头 |
| 低角度仰拍 | 低机位向上拍,增加英雄感 |
| 俯拍 / 鸟瞰 | 从高处向下拍 |
| 第一人称主观视角 | 从角色视角出发 |
| 快速摇镜 | 极速水平旋转产生运动模糊 |
| 机械臂跟随 | 多角度灵活跟随人物视线 |
| 宽幅航拍 | 无人机视角俯瞰 |

## 景别

| 术语 | 说明 |
|---|---|
| 极致特写 | 仅眼睛、嘴巴等细节 |
| 面部特写 | 人脸充满画面 |
| 中近景 | 头部和肩部 |
| 中景 | 腰部以上 |
| 全景 | 展示完整人物 |
| 远景 / 建立镜头 | 展示完整环境 |

## 运镜描述示例

- `镜头中景平稳跟拍`
- `镜头缓慢推近至近景`
- `镜头环绕主体半圈`
- `无人机视角俯瞰,缓慢后拉`
