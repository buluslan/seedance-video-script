# 能力边界与避坑 · pitfalls

> **何时读**:生成完自检时(SKILL.md 步骤5必读)。也用于生成时主动规避。

## 自检清单(生成完逐项过)

- [ ] 人物 ID 漂移?
- [ ] 参考人物 >4 人?
- [ ] 时间戳分段合理(没在 4-5 秒塞太多)?
- [ ] 台词小语种标注了?
- [ ] 任务指代正确(编辑/延长用`<视频N>`非"参考")?
- [ ] 风格明确了(防漂移)?
- [ ] 加了无字幕/无 Logo 约束?

## 2.0 已知坑 + 解法

### 人物 ID 漂移(换脸)
- 根因:参考图混用(人脸+全身+服装合并)/ 人脸占比过小
- 解法:大头照(仅头部特写)+ 全身照分开;**不用多视图/三视图**;重要素材 prompt 前置
- ⚠️ 不建议人物多视图(模型识别为多主体)

### 双胞胎问题
- 根因:主体定义不清 / 三视图致识别混淆
- 解法:清晰定义每个角色 + 名称标注对应图;加全局约束「视频全程禁止外形着装完全一致的人物,禁止分身双胞胎」;单人独立照

### 参考人物 >4 人不稳
- 现象:>4 人时人物数量不符/重复
- 解法:分组生成图片(每组 ≤4 人),再多图生视频

### 字幕乱入
- 无法 100% 避免 → 加「保持无字幕」「避免生成任何文字或字幕」;优先横屏(竖屏字幕概率高);参考图先去文字

### Logo / 水印
- 加「不要生成Logo」「不要生成水印」

### 风格漂移(写实→动漫)
- 加明确风格词(「2D 日漫风格」「3D 国风漫画」);或先把参考图转目标风格

### 特效不符
- 文字描述特效易无序跳变 → **用参考视频定义特效**(数字"2999"出场方式参考@视频1)

### 延长衔接跳变
- 剪映修补:前段末尾删 6 帧 + 后段开头删 1 帧;续写以转场切镜结尾

### 延长画质劣化
- 转白模视频再续写;控制续写次数

### 视频结尾噪音
- 剪映音频淡出(音量包络线末尾降至 0)

### 中文发音不准
- 多音字/生僻字 → 同音字替换("螭"→"吃")

### 音色参考不准
- 补细致音色特征描述(「低厚温润带细碎颗粒感中年男声」)

## 2.5 改善

| 坑 | 2.5 改善 |
|---|---|
| 油腻感 | ✅ 材质/肤质/眼神/光影/饱和度系统优化 |
| 字幕乱入 | ✅ 减少字幕与 BGM 不受控 |
| ID 漂移 | ⚠️ 改善(镜头衔接+多主体稳定),极多主体交互仍有空间 |
| 风格漂移 | ⚠️ 50 参考精准锁定+跨镜头复用 |
| 延长跳变 | ⚠️ 多轮延长保持连贯 |
| 画质劣化 | ⚠️ 4K+细节优化 |

## 2.5 新坑

- **50 参考不一定更好**:过多致模型困惑,需精选
- **4K 成本高昂**:普通创作者难承受
- **长镜头穿帮风险**:190 位创作者调查首位关心问题
- 模型局限:复杂运动物理合理性、极多主体交互稳定性仍有提升空间

## 2.5 反模式(prompt 常见错误)

1. **描述静止画面**(应写随时间的运动)
2. **含糊镜头**(「电影感」无效,应指明镜头+运动)
3. **把整段序列塞进一条 prompt**(每镜头一个清晰动作)
4. **参考不加标注**(必须说明每个参考用途)
