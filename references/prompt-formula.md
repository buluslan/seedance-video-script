# 提示词公式 · prompt-formula

> **何时读**:写每一段分镜时。两条公式任选——完整版 8 要素(精细控制)/ 快速版 SPACE(长叙事高效)。

## 核心理念(2.5 转变)

Seedance 是「多模态 AI 导演」,内部拆成**空间层**(画面有什么)+ **时间层**(事情如何变化)。
- 2.0:好的 prompt 是「工程型指令」(谁+场景+动作+镜头+时序),不是文案型形容
- 2.5 升级:从「描述一个瞬间」→「**描述一段时间的演进**」。写成一段随时间发展的运动,不是定格画面。外观交给参考素材,prompt 留给动作/运镜/节奏

## 公式 A:完整版 8 要素

```
精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件
```
- **必需**:精准主体、动作细节
- **建议**:其余 6 项

### 各要素怎么写
- **精准主体**:谁/什么。多素材时用 `将@图片N中的[2-3个稳定静态特征]定义为主体N`,后续持续用该标签
- **动作细节**:肢体细化(手/腿/头/肩)+ 程度量化(幅度/速度/力度)。**优先低缓连续小动作**(缓慢抬手/微微低头),规避狂奔大跳剧烈翻滚。写过渡衔接(借着转身惯性顺势抬手)。**情绪具象外化**(悲伤=低头肩膀微颤眼眶泛红,不写"很悲伤")
- **场景环境**:在哪
- **光影色调**:什么氛围(暖黄日光/冷蓝破晓)
- **镜头运镜**:怎么拍(见 camera-language.md,**一镜一种**)
- **视觉风格**:画风(防漂移,见下)
- **画质**:高清/电影质感/细节丰富
- **约束条件**:保持无字幕/不要 Logo/水印

## 公式 B:SPACE 快速版(长叙事高效)

| | 应包含 | 示例 |
|---|---|---|
| **S**ubject | 画面中是谁/什么 | 身穿红色冲锋衣的独行攀登者 |
| **P**erformance | 做什么,怎么做 | 翻上山脊,呼气凝成白雾 |
| **A**mbience | 场景、时间与光线 | 破晓时分的冰川,冷蓝色调 |
| **C**amera | 镜头类型+一个运动 | 宽幅航拍,缓慢后拉 |
| **E**xtra cues | 音频、节奏与转场 | 低沉的风声铺底,不间断长镜头 |

> SPACE 是 8 要素的精简版,额外强调音频指令(E)。与 8 要素不冲突,长场景用它更快。

## 画质 / 风格 / 约束词库

- **画质**:高清,细节丰富,电影质感,色彩自然,光影柔和
- **风格**(要明确,防漂移):赛博朋克冷蓝紫色调 / 复古胶片 / 日系清新 / 3D 国漫 CG / 2D 日漫 / 超写实
- **约束词**(规避瑕疵):保持无字幕 / 避免生成任何文字或字幕 / 不要生成 Logo / 不要生成水印

## 风格漂移提醒

参考图偏写实、又没强调风格时,易漂移成真人写实。想要 2D/3D 动漫→必须在 prompt 加明确风格词(「2D 日漫风格」「3D 国风漫画」),或先把参考图转成目标风格再用。
